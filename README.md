# Currency Converter (Конвертер валют)

**Автор:** 

## Описание проекта
Программа позволяет осуществлять конвертацию валют в режиме реального времени с помощью **ExchangeRate-API**. Локальная история операций сохраняется в JSON-файл и отображается в виде таблицы.

## Как получить API-ключ
1. Перейдите на сайт [exchangerate-api.com](https://www.exchangerate-api.com/).
2. Введите ваш Email и нажмите кнопку **"Get Free Key"**.
3. Перейдите по ссылке из письма, чтобы активировать аккаунт и скопировать ключ.
4. Откройте файл `main.py` и вставьте ваш ключ в переменную `API_KEY`.
